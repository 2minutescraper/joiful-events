# Joiful Events

Immersive, scroll-driven 3D website for Joiful Events (Imagine → Design → Celebrate).

- `index.html` is the whole site (Three.js r128 from cdnjs, no build step).
- `photos/` holds the portfolio images. Edit the `CONFIG` block near the top of the script to change photos, services, or contact details.
- Deployed on Vercel as a static site.
